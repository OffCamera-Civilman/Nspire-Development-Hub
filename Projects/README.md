# Projects

- UltraGBA: GBA emulator compatibility and diagnostics (first priority).
- PythonIDE: complete Python IDE with file browser, editor, and console (planned).
- FileManager: advanced file management (planned).
- PDFReader: PDF reading (planned).
- SystemMonitor: battery and hardware diagnostics (planned).

Each project will get its own documented build recipe and GitHub Actions job. Shared toolchain is planned under scripts/ and workflows.
