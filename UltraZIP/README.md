# UltraZIP 001

Experimental Ndless ZIP utility for TI-Nspire CX II CAS (target OS 6.4.0.74).

Initial features: ZIP listing, create ZIP containing one file, extract ZIP into a directory. Text-only prompt. File inputs use calculator-visible paths, and writing will not overwrite existing files. Password-protected archives are not supported.

**Safety:** First build is untested. Back up the calculator and test with disposable small files. Do not assume compatibility until a real on-device test succeeds.

The build runs through GitHub Actions (`.github/workflows/ultrazip.yml`). Download the workflow artifact `UltraZIP_001.tns` after a successful run.
